プライバシーポリシー

株式会社stageN（以下「当社」）は、統合経理・給与サービス「Zeiro（税路）」（以下「本サービス」）における利用者のプライバシー情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 収集する情報

本サービスでは、円滑な経理・給与計算およびサービス提供のため、以下の情報を安全に暗号化して収集・保管します。

  • アカウント情報: メールアドレス、氏名、PBKDF2（10万回反復）により暗号化ハッシュ化されたパスワード
  • 事業者マスタ情報: 会社名・屋号、決算月、法人番号、適格請求書発行事業者登録番号（インボイス番号）、事業所所在地
  • 会計・取引データ: 勘定科目、仕訳帳データ、銀行・クレジットカードの取引明細、総勘定元帳、決算監査ログ
  • 役員・従業員給与情報: 氏名、標準報酬月額等級、健康保険・厚生年金・雇用保険料、源泉徴収税額、給与支払明細データ

2. 情報の利用目的

収集した情報は、以下の目的でのみ使用します。

  • 複式簿記に基づく仕訳帳・試算表・決算書の自動生成
  • 役員報酬および従業員給与の適正な社会保険料・源泉所得税額の算出
  • 銀行およびカード取引明細の重複排除およびAI自動仕訳推論
  • 源泉所得税「納期の特例」集計表の作成および決算健全性監査の実施
  • 課金・サブスクリプションの管理および不正利用の防止

3. 決済処理（Stripe）について

有料サブスクリプション（プロプラン・ビジネスプラン）の決済処理は、PCI-DSS レベル1認定を取得している Stripe, Inc. に委託しています。クレジットカード番号等の機密決済情報は当社サーバーを一切通過・保存せず、Stripeの暗号化された安全なインフラ上で直接処理されます。

4. AI機能（Gemini API）の利用について

本サービスのAI仕訳推論機能では、Google Gemini API を使用しています。送信されるデータは勘定科目の推論および税区分の判定のみに使用され、GoogleによるAIモデルの学習や再利用には一切使用されません（API利用規約に準拠）。

5. データの保管・セキュリティ

本サービスは Cloudflare（Workers / D1 / R2）のエッジクラウドインフラ上に構築されており、通信はすべて TLS 1.3 / HTTPS による暗号化が行われています。データベースはテナントIDにより論理的に厳格に隔離されており、他社データと混在することはありません。

6. データの開示・訂正・削除

利用者は、本サービスのアカウント設定画面またはサポート窓口を通じて、いつでも自身の登録情報の確認、修正、および退会・データ削除を要求することができます。退会時には関連するすべての事業データが速やかに削除されます。

7. ポリシーの改定

当社は、法令の変更やサービス内容の改善に伴い、本ポリシーを改定することがあります。重要な改定についてはサービス内またはウェブサイト上でお知らせします。

8. お問い合わせ

本ポリシーに関するご質問やデータに関するお問い合わせは、サポートページまたは お問い合わせフォーム よりご連絡ください。
