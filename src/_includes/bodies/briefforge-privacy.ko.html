개인정보 처리방침

주식회사 STAGEN(이하 “회사”)은 BriefForge(이하 “서비스”) 이용 시 개인정보 보호에 최선을 다합니다.

BriefForge는 제품 탐색 도구입니다. GitHub로 로그인하며, 같은 OAuth 토큰으로 Issue를 생성합니다. 가설 생성을 위해 AI API로 Brief 내용이 전송될 수 있습니다.

1. 수집 정보

  • GitHub 로그인: 사용자 ID·이메일·표시명을 Cloudflare D1에 저장
  • 서비스 데이터: Brief·가설·Signals·결정 로그
  • GitHub 토큰: OAuth 액세스 토큰을 암호화 저장, Issue 생성에 사용
  • 접속 로그: Cloudflare 인프라 로그(IP·시각 등)가 남을 수 있음

2. AI 처리

가설 생성·리롤을 위해 Workers AI 또는 Gemini 등으로 Brief 내용이 전송될 수 있습니다.

3. 제3자

  • GitHub: 인증·Issue보내기
  • Cloudflare: 호스팅·D1·Workers AI
  • Google Gemini(선택): 가설 생성

4. 제공

법령에 따른 경우를 제외하고 개인정보를 판매·제공하지 않습니다.
