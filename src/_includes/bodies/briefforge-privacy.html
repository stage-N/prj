プライバシーポリシー

株式会社 STAGEN（以下「当社」）は、BriefForge（以下「本サービス」）におけるユーザーのプライバシーを尊重し、個人情報の保護に努めます。

本サービスはプロダクト探索ツールです。GitHub アカウントでログインし、同一の OAuth トークンで Issue エクスポートを行います。仮説生成のため AI API を呼び出す場合があります。

1. 収集する情報

  • GitHub ログイン時: GitHub ユーザー ID・メール・表示名を Cloudflare D1 に保存します
  • サービスデータ: Brief・仮説・Signals・決断ログなど、利用内容をサーバーに保存します
  • GitHub トークン: OAuth アクセストークンを暗号化して保存し、Issue 作成に使用します
  • アクセスログ: Cloudflare のインフラログ（IP・リクエスト時刻等）が技術的に記録される場合があります

2. AI 処理

仮説生成・リロールのため、入力した Brief 内容が Workers AI または Gemini 等の AI プロバイダに送信されることがあります。

3. 第三者サービス

  • GitHub: 認証・Issue エクスポート
  • Cloudflare: ホスティング・D1・Workers AI
  • Google Gemini（任意）: 仮説生成

4. 第三者への提供

法令に基づく場合を除き、ユーザーの個人情報を第三者に販売・提供しません。

5. お問い合わせ

本ポリシーに関するお問い合わせはサポートページよりご連絡ください。

6. ポリシーの変更

本ポリシーは予告なく変更される場合があります。変更後のポリシーは本ページに掲載した時点で効力を生じます。
